# Linguagem ubíqua

| Termo | Significado na oficina |
|---|---|
| Ordem de serviço (OS) | Registro do atendimento do veículo. Tem cliente, placa vinculada, serviços solicitados, status e histórico. |
| Diagnóstico | Etapa em que o mecânico define o que deve ser orçado. A OS volta para cá quando um orçamento é rejeitado. |
| Serviço solicitado | Trabalho indicado na abertura. Serve como base para o primeiro orçamento. |
| Orçamento | Proposta calculada com os serviços, peças e insumos e seus preços no momento da emissão. |
| Revisão | Número da proposta dentro da OS. O cliente informa a revisão na decisão. |
| Peça | Material como um filtro. |
| Insumo | Material de consumo como o óleo, cadastrado na unidade que a oficina usa para controlar o saldo. |
| Saldo | Quantidade física registrada de um material. |
| Reserva | Quantidade comprometida com ordens aprovadas. Ainda faz parte do saldo. |
| Disponível | Saldo menos reserva. É o máximo que uma nova aprovação pode comprometer. |
| Baixa | Consumo de material reservado quando a OS é finalizada. |
| Código de acompanhamento | Segredo exclusivo da OS entregue ao cliente junto com a rota de acompanhamento. |
| Tempo de execução | Tempo entre a aprovação do orçamento e a finalização da OS. |
